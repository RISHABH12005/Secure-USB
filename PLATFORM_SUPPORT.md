# Platform support and install downloads

## Current app status

SecureUSB is currently a Python/Tkinter desktop application. The release workflow builds Windows, macOS, and Linux desktop packages. Build downloads are published as GitHub Actions artifacts after a successful workflow; versioned GitHub Releases are published when a v* tag is pushed.

| Platform | Build output | Status and limitations |
|---|---|---|
| Windows 10/11 x64 | SecureUSB.exe and SecureUSB-Setup.exe | Setup wizard generated by CI; unsigned unless a code-signing process is configured. |
| macOS | SecureUSB-macOS.zip containing an app bundle | Unsigned and not notarized by default; Gatekeeper may warn. |
| Linux | SecureUSB-Linux executable | Built on Ubuntu; desktop libraries and Tk availability vary by distribution. |
| Android | No APK yet | Requires a dedicated mobile UI, Android file picker, secure credential storage, and vault-format compatibility tests. |
| iPhone/iPad | No IPA yet | Requires a dedicated iOS app, Apple signing, and TestFlight/App Store or authorized development distribution. |
| Car stereos / standalone players | Encrypted vault playback unsupported | These devices cannot decrypt .smusb files; export ordinary audio files for compatible players. |

## Download desktop builds

1. Open the repository's Actions tab.
2. Select the latest successful Test and package SecureUSB workflow run.
3. Download the artifact for your operating system.
4. On Windows, run SecureUSB-Setup.exe; SecureUSB.exe is also included.
5. On macOS, extract the ZIP and open the app bundle. The default build is unsigned.
6. On Linux, download and run the executable. If it does not launch from the file manager, try it from a terminal.

For a tagged release, open the repository's Releases page and download its assets.

## Mobile app work still required

The desktop executable is not an Android APK or iOS app. Mobile needs a separate UI and platform integration. Before claiming cross-device vault compatibility, mobile builds must use the same documented vault format, safely handle passwords and temporary plaintext, and pass shared test vectors for create/unlock/add/extract/delete/backup. Do not use a mobile build to modify the only copy of an important vault until compatibility tests pass.

## Data safety

- Keep original songs and a second copy of important vaults until the app is fully validated.
- Do not format the USB drive to install this software.
- The vault encrypts its contents, not the entire USB drive.
- Deleting a song from the vault creates an encrypted backup first; add and rename operations do not create automatic backups.
